# Consultorios

Odoo 19 addons for clinical scheduling, medical records, and related practice workflows.

These modules come from [filoquin/emr](https://github.com/filoquin/emr) (branch `19.0`, commit `b7a1e9c6d29cd0cb5d38dc7644216ece4da05aef`). The imported modules keep their original licenses and authorship.

## Modules

- `emr` — EMR - Turnos e Historia Clínica
- `emr_account_cashbox` — EMR - Caja
- `emr_covid_screening` — EMR - Triage COVID (histórico)
- `emr_endoscopy` — EMR - Endoscopía
- `emr_odontology` — EMR - Odontología
- `emr_prescription` — EMR - Recetas
- `emr_whatsapp` — EMR - Avisos por WhatsApp

Add this repository to the Odoo 19 addons path and install the modules you need.
